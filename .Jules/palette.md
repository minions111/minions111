## 2025-05-15 - [CommandBar Keyboard Navigation]
**Learning:** Implementing keyboard navigation for auto-suggestions in a high-density terminal interface significantly improves workstation efficiency. Proper ARIA attributes (combobox, listbox, option) are essential for screen reader users to understand the relationship between the command input and the filtered suggestions.
**Action:** Always include ArrowUp/ArrowDown/Enter/Escape handlers and W3C autocomplete ARIA patterns when building search-driven command interfaces.
