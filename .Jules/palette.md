## 2026-05-02 - Enhanced Command Bar Accessibility and Navigation
**Learning:** Implementing a professional terminal-style command bar requires more than just an input. Full WAI-ARIA combobox pattern (role="combobox", aria-expanded, aria-controls, role="listbox", role="option") is essential for screen reader parity. Additionally, memoizing the suggestion list and selection logic is critical in high-frequency update environments (like a terminal with a ticking clock) to prevent "focus jumps" or losing the selected index on every tick.
**Action:** Always use `useMemo` for static command registries and `useCallback` for command handlers when passed to components with internal stateful focus (like CommandBar). Use the "immediate-focus" pattern where the first ArrowDown both reveals the list and selects the first item for a snappier feel.
