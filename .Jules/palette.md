## 2025-05-15 - Bloomberg Terminal Workstation UX Optimization

**Learning:** Institutional financial interfaces prioritize "fingers on keys" speed and efficiency. A terminal simulation without full keyboard navigation for core interactions (like the Command Bar) fails the "vibe check" for institutional users, regardless of visual fidelity.

**Action:** Always implement full keyboard support (Arrow keys, Enter, Escape) and WAI-ARIA Combobox patterns for any command-entry or search interface to ensure high-speed accessibility.
