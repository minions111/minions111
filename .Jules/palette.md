## 2025-05-15 - Keyboard Navigation for Terminal Command Bar
**Learning:** For a "fingers on keys" workstation experience, keyboard navigation for auto-suggestions is not just a "nice to have" but a core requirement. Implementing the W3C ARIA Combobox pattern ensures that these power-user features remain accessible to screen reader users.
**Action:** Always implement `ArrowUp`/`ArrowDown` navigation and `aria-activedescendant` for any custom dropdown or suggestion list in this repository.
