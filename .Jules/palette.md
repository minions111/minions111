## 2025-05-14 - [CommandBar Keyboard Navigation & Accessibility]
**Learning:** For a command-driven terminal interface, keyboard-only navigation is a core UX requirement, not just an accessibility feature. Implementing the W3C combobox pattern (aria-activedescendant) ensures the interface remains accessible while providing the "fingers on keys" experience professional users expect.
**Action:** Always prioritize keyboard shortcuts and ARIA combobox patterns for search/command inputs in this workstation environment.
